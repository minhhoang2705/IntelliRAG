# GitHub Secrets Configuration Guide

## Overview

This guide walks through setting up the required GitHub repository secrets for CI/CD automation.

## Prerequisites

- GitHub repository: `your-org/IntelliRAG` (update with your actual repo)
- Admin access to the repository
- GCP service account key (generated by `scripts/setup-github-actions-sa.sh`)

---

## Step-by-Step Instructions

### 1. Navigate to Repository Secrets

1. Go to your GitHub repository
2. Click **Settings** (top navigation)
3. In the left sidebar, expand **Secrets and variables**
4. Click **Actions**
5. Click **New repository secret** button

---

### 2. Add Required Secrets

Add each of the following secrets one by one:

#### Secret 1: GCP_SA_KEY

**Purpose**: Service account credentials for GCP authentication

**Steps**:
1. Click **New repository secret**
2. Name: `GCP_SA_KEY`
3. Secret: Paste the content from `github-actions-key.base64`
   ```bash
   # Get the base64-encoded key
   cat github-actions-key.base64
   ```
4. Click **Add secret**

## Security Best Practices

### DO:
- ✅ Rotate service account keys regularly (every 90 days)
- ✅ Use least-privilege IAM roles
- ✅ Audit secret access in GitHub Actions logs
- ✅ Keep `github-actions-key.json` secure and **never commit to git**

### DON'T:
- ❌ Share secrets via email, Slack, or other channels
- ❌ Print secrets in GitHub Actions logs
- ❌ Commit secrets to version control
- ❌ Use production secrets in development workflows

## Rotating Service Account Keys

When you need to rotate the service account key:

```bash
# 1. Create a new key
gcloud iam service-accounts keys create github-actions-key-new.json \
  --iam-account=github-actions-cicd@intellirag-aide1-capstone.iam.gserviceaccount.com

# 2. Base64 encode the new key
cat github-actions-key-new.json | base64 -w 0 > github-actions-key-new.base64

# 3. Update GitHub secret GCP_SA_KEY with new base64 content

# 4. Test CI/CD workflows with new key

# 5. Delete old key (get key ID first)
gcloud iam service-accounts keys list \
  --iam-account=github-actions-cicd@intellirag-aide1-capstone.iam.gserviceaccount.com

gcloud iam service-accounts keys delete <KEY_ID> \
  --iam-account=github-actions-cicd@intellirag-aide1-capstone.iam.gserviceaccount.com

# 6. Securely delete old key files
shred -vfz -n 10 github-actions-key.json
shred -vfz -n 10 github-actions-key.base64
```

## Troubleshooting

### Problem: "Secret not found" error in GitHub Actions

**Solution**: Verify secret name matches exactly (case-sensitive)
```yaml
# Correct
env:
  GCP_PROJECT_ID: ${{ secrets.GCP_PROJECT_ID }}

# Wrong
env:
  GCP_PROJECT_ID: ${{ secrets.gcp_project_id }}
```

### Problem: GCP authentication fails in CI workflow

**Solution**: Verify GCP_SA_KEY is properly base64-encoded
```bash
# Test decoding
cat github-actions-key.base64 | base64 -d | jq .
```

### Problem: Cannot access secret values

**Reason**: GitHub Secrets are write-only for security
**Solution**: Re-add the secret if you need to change it
